# Sania Rakhangi – Portfolio Website

A personal portfolio website that showcases my work across software engineering, machine learning, and UI/UX design through a narrative-inspired dark academia experience.

Rather than presenting projects as isolated entries, the portfolio is designed as a digital archive where visitors explore projects, skills, and experiences through the atmosphere of a library filled with stories, research, and discovery. Inspired by dark academia literature and story-driven fantasy games, every section contributes to a cohesive journey that reflects both my technical and creative interests.

---

## Design Concept

The website combines dark academia aesthetics with modern web design to create an immersive experience.

- The **Hero Section** introduces visitors to the world of the portfolio, much like the opening chapter of a novel.
- The **Projects Section** presents projects as books on a shelf, each containing its own story, challenges, and solutions.
- The **Skills Section** is inspired by RPG skill trees and character attributes, connecting skills directly to the projects where they were applied.
- The **About Section** resembles a character profile or game handbook entry, highlighting the principles and experiences that shape my work.
- The **Contact Section** transforms a traditional contact form into a handwritten letter, reinforcing the narrative theme.

Project case studies are designed to be read like chapters of a book, guiding readers through the problem, process, decisions, and outcomes in a structured storytelling format.

## Featured Projects

### Vehicle Parking Management System

A full-stack MERN application featuring parking slot management, automated booking workflows, monitoring, and deployment automation.

**Technologies:** React, Node.js, Express.js, MongoDB, Docker, Kubernetes, Jenkins

### Sketch → Face: CLIP-Guided GAN

A multimodal machine learning project that generates realistic facial images from forensic sketches using CLIP-conditioned GAN architectures.

**Technologies:** PyTorch, GANs, CLIP, Computer Vision

### M-Indicator App Redesign & Testing

A UX case study focused on improving navigation, information architecture, accessibility, and commuter workflows within the M-Indicator application.

**Tools:** Figma, User Research, Heuristic Evaluation, Usability Testing

## Getting Started

### Clone the Repository

```bash
git clone <repository-url>
```

### Navigate to the Project Directory

```bash
cd portfolio-website
```

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
